## 🚀 Projeto em destaque

### 🎨 InovArt

O **InovArt** é uma plataforma criada para valorizar e ampliar a
visibilidade de artesãos e de seus trabalhos na região de Varginha.

Durante o projeto, tive a oportunidade de trabalhar com uma aplicação
web completa, passando pela construção da interface, organização dos dados,
autenticação e integração com banco de dados.

**Principais tecnologias:**

`TypeScript` • `React` • `Next.js` • `Supabase` • `Tailwind CSS`

➡️ [Conhecer o InovArt](https://github.com/KyyKelvin/inovart)
